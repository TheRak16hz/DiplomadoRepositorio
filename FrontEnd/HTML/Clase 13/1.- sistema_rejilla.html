Uno de los mayores beneficios de boostrap es su sistema de cusdricula responsivo (grid system). Esto significa que los diseños se adaptan automaticamente a diferentes tamaños de pantalla, como computadoras, de escritorio, tabletas y telefonos moviles, sin que el desarrollador tenga que escribir codigo CSS personalizado para cada dispositivo
